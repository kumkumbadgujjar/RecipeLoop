# RecipeLoop

RecipeLoop is a modern recipe discovery web application rewritten in React, TypeScript, and Tailwind CSS (migrated from the original Android Jetpack Compose codebase).

## Features
- **Browse Recipes**: Live recipes from the recipe API featuring high-resolution food images, preparation time, difficulty level, and cuisine tags.
- **Cuisine Filters**: Filter dynamically by cuisine (Italian, Asian, Mexican, Pakistani, American, etc.) or explore all recipes.
- **Detailed Recipe View**:
  - Hero image showcase with fallback handling
  - Recipe overview badges (Cuisine, Difficulty, Meal Type)
  - At a glance stats: Prep time, Cook time, Servings, and Calories per serving
  - Bulleted Ingredients list
  - Step-by-step numbered Cooking Instructions
- **Responsive Layout**: Designed to mirror the clean Material 3 mobile experience while providing a smooth desktop interface.

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
